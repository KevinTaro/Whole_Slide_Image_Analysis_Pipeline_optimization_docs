整體：沿用既有前端工作台（frontend/：React 19 + OpenSeadragon 6 + react-query + Tailwind v4）。這頁只多一個「Hybrid 分析」流程，不新造框架。

  • 畫面 1（圈選）：沿用 SlideViewer.tsx 的 OSD 檢視，加一個 ROI 矩形選取（OSD 有現成的框選 plugin / overlay，不要手搓）。切片清單來自 GET /api/tiles。ROI 座標是 slide 像素。
  • 「開始分析」：對應 PipelinePanel.tsx，帶 IHC + DISH 的 slide_id 與 ROI 打 POST /api/hybrid/tile（現有 endpoint，走 precut + run_batch），回傳 job_id。
  • 畫面 2（分析中）：useJob(jobId) 每 1.5s 輪詢 GET /api/jobs/{id}（非 WebSocket，符合 05 資料流合約）。M0→M4 為單一長任務，串行、fail-fast。
  • 畫面 3（結果）：完成後 overlay_slide.tiff 需先產 subifd=False 的 viewer 副本才能餵 OSD（見 09）；summary.txt 直接讀文字渲染成報告卡；report.csv 提供下載。

護欄：前端只認 slide_id，永不碰檔案系統路徑；tile server 不做影像處理。詳見 04 / 05 / 10。
