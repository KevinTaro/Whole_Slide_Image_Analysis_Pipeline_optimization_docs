# Discovered but not implemented — full audit of docs 01–25 + measurement/*.md

> Compiled 2026-07-26, after reading every document in `docs/hybrid-pipeline/` (01–25, the two
> playbook docs, README, and every file in `measurement/`, excluding the `-zh` translations and the
> HTML files). **Purpose**: a single place listing every idea, candidate, or finding that this
> project's own Discover/Analyze/Plan work surfaced but that never resulted in a pipeline code
> change — whether it is still open, was explicitly rejected after measurement (stop-lossed), or is
> blocked on something else. This is a one-time compiled audit, not a living backlog — for the
> ranked, actively-maintained "what's left" list, use [`19-open-backlog.md`](./19-open-backlog.md)
> and [`measurement/bottleneck-list.md`](./measurement/bottleneck-list.md), which this doc
> cross-references rather than duplicates. Update this file only if you do a similarly full re-audit;
> for day-to-day tracking, 19 is the authority.
>
> **Reading key** — every row is one of:
> - 🟢 **Open / actionable** — identified, not built, not rejected. Real backlog.
> - 🟡 **Gated / blocked** — built or ready, but waiting on another item (validation, a decision, an
>   environment fix) before it can ship or be attempted.
> - 🔴 **Stop-lossed** — measured (or reasoned) and explicitly rejected. Recorded so nobody re-proposes
>   it without new evidence.
> - ⚪ **Never executed** — a measurement or investigation step itself was planned but never run
>   (distinct from a *candidate* being rejected — here the *question* was never answered).
> - ✅ **Closed since this audit was compiled** — built, or answered by measurement, in a later
>   round. Kept in place (rather than deleted) so the audit stays a complete ledger of what was
>   ever discovered; the row names the document that closed it.
